# ORBITA — Flujo funcional de referencia

## Historia principal

**OBJETIVO → RED → EVIDENCIA → OPORTUNIDAD → ACCIÓN**

1. Abrir ORBITA y entrar a `HOY`.
2. Usar el panel `AGENTE RELACIONAL`.
3. Objetivo de referencia: `Estoy levantando una ronda pre-seed`.
4. Ejecutar `ANALIZAR MI RED`.
5. En el dataset demo se priorizan Mateo Fernández, Ana Beltrán y Valentina Ríos.
6. Abrir un resultado para inspeccionar hechos usados, inferencia explícita, confianza y siguiente acción.
7. Test negativo de referencia: `Quiero aprender guitarra` debe devolver cero oportunidades.

## Principio de producto

ORBITA no inventa una red. Razona solamente sobre contexto registrado en el workspace. Si no reconoce una intención relacional con evidencia suficiente, no crea una recomendación.
