# ORBITA CANON — V0.2

Status: **FUNCTIONAL MVP FOUNDATION**

## Definition

ORBITA is an agent of relational intelligence.

It does not maximize contacts. It helps a person preserve context, honor commitments and develop valuable human relationships over time.

## Initial user

Founders and entrepreneurs with active professional networks.

## Manual MVP thesis

Before ORBITA ingests external sources, the product must prove that its relational model is useful with information the user chooses to capture.

### Core loop

1. Capture what happened.
2. Attach it to a person.
3. Preserve context and commitments.
4. Surface time-sensitive signals.
5. Prepare the next interaction.
6. Record the outcome.

## Current product primitives

- Person
- Interaction
- Commitment
- Opportunity
- Meeting
- Relationship circle
- Cadence
- Follow-up

## Trust rules

- No fabricated facts.
- No hidden relationship scores.
- User-defined circles are intent, not value judgments.
- Automatic signals must be explainable from stored data.
- Meeting Briefs must distinguish stored context from future AI inference.
- Destructive actions are explicit.
- Data remains exportable.
