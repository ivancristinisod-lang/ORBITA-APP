# ORBITA — Design System V0.4

## Direction

The V0.3 visual language remains canonical. V0.4 does **not** redesign it; it improves legibility and interaction clarity.

## Palette

- Background: `#070807`
- Panel: `#101110`
- Acid: `#DCFF00`
- Cobalt: `#2747FF`
- Paper: `#E9DFCB`
- Alert: `#FF5738`

## Readability rule

No core product information should depend on 6–8px text at normal desktop scale. Small labels remain compact, while names, actions, form controls, relationship context and event information use a materially larger scale.

## Interaction rule

Anything that can be changed should expose an obvious path to **Edit** near the information itself or inside its relationship detail. Derived metrics are not manually editable.

## Density rule

Dense does not mean cramped. Containers should preserve:

- readable line-height;
- minimum action targets;
- predictable padding;
- no accidental horizontal page overflow;
- internal scrolling only where it has a clear purpose (calendar, long lists, drawers).

## Product hierarchy

1. What needs attention.
2. Who the relationship is with.
3. What happened / what is next.
4. Context.
5. Secondary metadata.
