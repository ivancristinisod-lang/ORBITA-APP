# ORBITA — Design System v0.3

## Dirección
Editorial brutalista, tecnológica y humana. Alta densidad, jerarquía extrema, bordes rectos, lectura rápida y color con función.

## Paleta canónica
- Background: `#070807`
- Panel: `#101110`
- Acid: `#DCFF00`
- Cobalt: `#2747FF`
- Ivory: `#E9DFCB`
- Orange/Risk: `#FF5738`
- Green/Healthy: `#62B36D`

## Jerarquía
- Número de módulo 01–05: acid.
- Título principal: condensed / uppercase / ivory.
- Azul: acción primaria, agenda y datos estructurales.
- Acid: foco, salud, selección y call to action.
- Naranja: riesgo o atención real.
- Marfil: bloques humanos / contraste editorial.

## Regla
Color no decorativo: cada color debe comunicar estado, acción o jerarquía.
